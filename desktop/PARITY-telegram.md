# Parvane ↔ Telegram Desktop — паритет функций и внешнего вида

Цель: полная копия клиента Telegram Desktop (внешний вид 1:1 + все функции), кроме
ботов и мини-приложений. Этот документ — рабочая карта: как устроен оригинал (по
исходникам tdesktop, которые у нас уже в `desktop/tdesktop/`), что уже нативно, что
мы подменяем своими виджетами, чего нет, и план доведения.

## ГЛАВНЫЙ ПРИНЦИП (почему это выполнимо)

Наш клиент — **форк Telegram Desktop**. Весь нативный UI Telegram уже в репозитории.
Мы НЕ рисуем интерфейс сами — мы синтезируем TL-объекты (`MTPMessage`, `MTPUser`,
`MTPChat`, `MTPDocument`…) и скармливаем их штатному UI через `Data::Session`
(`addNewMessage`, `processUser`, `processChat`). Поэтому чаты, сообщения, медиа,
список диалогов, профили, настройки **уже выглядят как Telegram 1:1** — это родной
код tdesktop.

Отсюда правило паритета: **любую функцию делаем через НАТИВНЫЙ модуль tdesktop,
кормя его нашими данными из NATS. Свои QWidget/QPainter — только когда нативного
пути реально нет.** Каждый самодельный виджет = отклонение от «1:1» и его надо
устранять.

Проверка (греп по `parvane/*.cpp`): единственный файл с кастомными виджетами —
`parvane_video_window.cpp` (окно звонка). Всё остальное — нативное. Значит главный
визуальный разрыв — ЗВОНКИ.

## Карта модулей tdesktop (SourceFiles/)

- `history/` — лента сообщений (HistoryView::ListWidget/Message), композер, медиа,
  реакции, ответы, пересылки, закрепы. Мы уже кормим это через `addNewMessage`.
- `dialogs/` — список чатов слева (папки, поиск, счётчики, свайпы).
- `data/` (76 файлов) — модель: `Data::Session`, `HistoryItem`, `DocumentData`,
  `PhotoData`, `PeerData`/`UserData`/`ChatData`/`ChannelData`. Наш мост живёт тут.
- `calls/` — НАТИВНЫЙ UI звонков: `Calls::Panel` (окно), `Calls::Instance`
  (менеджер), `Calls::Call` (звонок, `final`, завязан на MTProto/tgcalls),
  `calls_userpic`, `calls_video_bubble`, `calls_video_incoming`,
  `calls_signal_bars`, `calls_emoji_fingerprint`, `calls_top_bar`, `calls.style`.
- `settings/` — экран настроек (14 разделов: аккаунт, приватность, уведомления,
  чаты, папки, продвинутое…).
- `info/` — профиль пользователя/чата, общие медиа, участники.
- `boxes/` (61 файл) — все диалоги-«боксы» (создать группу, выбрать контакты,
  отправить файл, стикеры и т.д.).
- `chat_helpers/` — панель эмодзи/стикеров/GIF, поле ввода с форматированием.
- `media/` — плеер аудио/видео, просмотрщик, запись голосовых (waveform).
- `window/` — главное окно, секции, топ-бар, темы.
- `ui/` — базовые виджеты и стили (rp-widgets, кнопки, лейблы).
- `overview/`, `profile/`, `export/`, `passport/`, `payments/`, `poll/`,
  `statistics/`, `iv/` (instant view), `platform/` (интеграция с ОС).

## Инвентаризация: функция → нативный модуль → наше состояние

Легенда: 🟢 нативно (выглядит 1:1) · 🟡 частично/кастом (надо на нативное) ·
🔴 нет.

### Сообщения 1-на-1
- Текст, доставка/прочтение, typing, online — 🟢 (кормим нативный history).
- Медиа: фото/видео/файлы/голос/видеосообщения — 🟢 рендер; голос waveform — 🟡
  (считаем `audioCountWaveform`, но надо убедиться в 1:1 виде и превью видео).
- Реакции, закреп, ответы, редактирование, удаление, пересылка — 🟢.
- Форматирование текста (жирный/курсив/моно/спойлер/ссылки/цитаты) — 🔴 (нативный
  композер умеет; надо прокинуть entities в наш `MessageContent`).
- Превью ссылок (webpage) — 🔴 (нужен `MTPWebPage` + сервис превью).
- Черновики, «Избранное» (Saved Messages), переслать в любой чат — 🔴/🟡.

### Группы и каналы
- Группы/каналы, роли, права постинга, медиа/реакции/пин — 🟢 (синтез MTPChat).
- Админка (бан/мьют/права), инвайт-ссылки, @упоминания, треды/обсуждения,
  счётчики прочтений, «прочитали N» — 🔴.

### Звонки — ГЛАВНЫЙ РАЗРЫВ
- Аудио/видео/групповые, WebRTC, MITM-защита (Ed25519+SAS) — 🟢 функционально.
- UI — 🔴/🟡: сейчас САМОДЕЛЬНОЕ окно `parvane_video_window` (не похоже на
  Telegram), рингтон есть. Надо: экран звонка на нативных стилях `calls.style` и
  виджетах (`calls_userpic`, `calls_video_bubble`, `calls_video_incoming`,
  `calls_signal_bars`, SAS через `calls_emoji_fingerprint`), топ-бар активного
  звонка (`calls_top_bar`). `Calls::Call` переиспользовать нельзя (final+MTP) —
  строим Parvane-панель из тех же стилей/виджетов, driven нашим CallManager.

### Развлекательный слой
- Стикеры/GIF/кастом-эмодзи — 🔴 (нативная панель `chat_helpers`; нужен свой
  шард-каталог стикеров + `MTPDocument` со стикер-атрибутами).
- Опросы (poll) — 🔴 (`poll/`, `MTPPoll`).
- Геолокация/live-локация, контакты-вложения — 🔴.

### Приватность/безопасность
- TLS транспорта — 🟢. Защита звонков — 🟢.
- E2E-шифрование текста/медиа/групп (Olm+Megolm, sealed sender, ротация ключей,
  safety numbers) — 🟢 (лучше «секретных чатов»: E2E по умолчанию везде).
- Самоуничтожение/TTL — 🟢 текст (нативный ttl_period, TTL внутри E2E-content);
  медиа — 🟡 (inject не прокидывает ttl).
- Локальный персист истории (переживает рестарт/релогин) — 🟢.

### Приложение
- Настройки, профили, общие медиа, поиск — 🟢 нативно (частично не подключены к
  нашим данным — проверить каждую вкладку).
- Папки, архив, закреплённые чаты — 🟡/🔴.
- Уведомления (нативные) — 🟡 (проверить, что триггерятся на наши сообщения).
- Темы оформления — 🟢 нативно (рескин Фазы 5 — по желанию).

### Явно НЕ делаем (просьба пользователя)
- Боты и Bot API, мини-приложения Telegram. Также вне ядра: Stories, Premium,
  платежи.

## План реализации (приоритеты)

1. **P0 — Нативный экран звонка.** Убрать `parvane_video_window`, собрать панель на
   `calls.style` + нативных call-виджетах, привязать к нашему `CallManager`
   (состояния Outgoing/Incoming/Active/Ended, mute, hangup, видео, self-preview,
   SAS через `calls_emoji_fingerprint`). Топ-бар активного звонка. Рингтоны уже
   нативные. → визуально «звонок как в Telegram».
2. **P1 — Форматирование текста + entities** (жирный/курсив/моно/спойлер/ссылки):
   прокинуть `entities` в `MessageContent` (send+receive), рендер нативный.
3. **P1 — Превью ссылок** (webpage), черновики, «Избранное», переслать-в-любой-чат.
4. **P1 — Уведомления**: убедиться, что нативные уведомления идут на входящие.
5. **P2 — Стикеры/GIF/эмодзи**: шард-каталог + нативная панель chat_helpers.
6. **P2 — Опросы, геолокация, контакты.**
7. **P2 — Админка групп/каналов, инвайт-ссылки, @упоминания, треды.**
8. **P3 — E2E-шифрование текста (секретные чаты), TTL.**
9. **P3 — Папки/архив, аудит всех вкладок настроек/профиля на наши данные.**

Правило на каждый пункт: сперва найти нативный модуль, потом прокинуть в него наши
данные из NATS; свои виджеты — только если нативного пути нет.
