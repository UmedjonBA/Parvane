# «Файлы»: время создания папки

`cloud.v1.CloudCreate.mtime_ms` у папки — момент её создания, мс UTC; 0 — неизвестно (папка старше правки). Нужен
для даты «Изменён» у пустой папки: раньше у папки время бралось только из содержимого (последнее изменение
вложенного файла), и пустая папка стояла без даты.

Где хранится: в регистре создания узла (`Created.at_ms`) — только у папки; у файла там 0, его время живёт в
содержимом (`Body.mtime_ms`), как и было. В снимке домена — отдельное поле `cloud.v1.CloudEntry.created_ms` (25):
поле `mtime_ms` записи снимка занято временем содержимого, а у узла, созданного папкой, содержимое тоже может
оказаться (спорные создания одного узла разными видами) — общее поле ломало бы равенство «снимок + хвост == вся
история».

Кто ставит: клиент при создании папки (`mtime` операции `create`); движок только хранит и отдаёт в дереве
(`mtime` узла-папки). Дата строки папки на экране — наибольшее из её времени и времени вложенного.

Что видит сервер: ничего — операция и снимок едут зашифрованными, как остальные поля домена.

Слияние: поле входит в регистр создания (побеждает создание с большей меткой; при равных метках — больший вид,
«от кого», затем время), отдельной логики нет.
