# Сервис скачивания для «Музыки»

Необязательная часть «Музыки» Parvane (spec 039, этап B): ищет треки в сети и скачивает их в папку общей
библиотеки. Шард `music` решает, какой файл — тот самый трек; сервис только выполняет поиск и загрузку.
Источники (YouTube, SoundCloud) — на ответственности администратора сервера: включайте сервис, только если
это допустимо там, где работает ваш сервер.

Включение: профиль compose `music-fetch` вместе с профилем `music` и переменная шарда
`PARVANE_MUSIC_FETCH_URL=http://music-fetch:9350`. Контракт и переменные — в начале `server.py`.

Свой сервис можно подставить вместо этого: достаточно отвечать на те же четыре запроса.
