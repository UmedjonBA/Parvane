# WEB-A4 acceptance matrix

This matrix tracks the current-function acceptance gate from `WEB-ROADMAP.md`.
`Automated` means the behavior runs against the production-like NATS, gateway,
and shard stack (`scripts/run_web_e2e.sh`: NATS with `server.prod.conf`,
shards from `backend/target/debug`, gateway, TURN when `go` is available).
Security-only coverage does not count as a user-facing happy path. Runners are
executed one at a time; `scripts/run_web_tests.sh` lists every scenario.

## Protocol v2 (spec 007) — rows for the v2 stack

Since T110 (7 Oct 2026) the web client runs the v2 stack only: the WASM
engine (`src/lib/parvane-protocol`) for messaging, groups, calls, typing and
presence, and the v2 bridge (`src/api/parvane/v2/bridge.ts`) for login,
profiles, search, devices, linking, previews, ICE and files. There is no v1
transport, no v1 cryptography (Olm/Megolm) and no protocol switch; every
`scripts/e2e_web_*.mjs` scenario in the sections above runs on this stack.
